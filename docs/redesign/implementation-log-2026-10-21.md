# Implementation log, 2026-10-21

The judgement calls made while building `REDESIGN.md` Part 4 unattended, by workstream.

## P2

- **What:** an example puts on screen only the fields: now, monthly, "מתי" with its date or ages, and the "already invested" box. The web drops what the core's `situations` set beyond them: "עוד לא יודעים" no longer answers the cushion decision (₪17,000 of expenses), and "כרית ביטחון" no longer carries a hidden 6‑month date. **Why:** principle 19; Part 4 forbade Rust changes in P2. **Where:** `web/src/lib/examples.ts` (`exampleAnswers`). P1, or a later round, should make `crates/core/src/situations.rs` set only these, so the web's filter becomes a no‑op.
- **What:** "לשעת חירום" asks the core `needs_any_day` with `Horizon::Unknown`: the box shows a sentence, not a date, so no date is sent. The core then words the fund's line "לטווח של 10 שנים" (its no‑date term), where the old cushion example said 6 months. **Why:** principle 19 (nothing set that isn't on screen). **Where:** `examples.ts` `horizonOf`. For P1/§4.9: the any‑day route's words shouldn't name a term the visitor never gave.
- **What:** the "already invested, in a portfolio at my bank" checkbox (from `InputsCard.dc.html`, all modes) sits between the money now and the monthly amount. It is the visible field the "כבר יש לי תיק בבנק" example sets (`Situation::ExistingPortfolio`), so that example stays. It's always enabled; the frame disabled it at ₪0. **Why:** Part 4's text doesn't mention it, but the accepted frame has it, and without it that example would set a hidden flag (principle 19). Enabled: a disabled but ticked box would be state the visitor can't change. **Where:** `Questions.svelte`, `app.setInvested`.
- **What:** an empty "בעוד" field is now an input the core can't use ("צריך לשמור את הכסף לפחות חודש"), with the last answer faded, and not a date not known: "עוד אין תאריך" says that. Empty ages say "מלאו את הגיל שלכם היום ואת גיל הפרישה." (my wording, `t.fillAges`), instead of the core's "המחשבון מחשב עד 50 שנה" for age 0. Switching to "בפרישה" for the first time leaves the ages empty, not 45/65. **Why:** principles 5 and 19 (no invented facts), and 21 (an empty field mustn't flip "מתי" under the visitor's cursor). **Where:** `app.svelte.ts` (`setHorizonMonths`, `inputError`), `WhenField.svelte`.
- **What:** the four parts of the box under "מתי" take turns in one grid cell, and so do every state of the status line, including a hidden copy for each example's name with "↺ חזרה למספרים שלכם". Each is as tall as its tallest state at the current width, rather than a fixed pixel height. On the desktop's narrow column, "דוגמה: לדירה או למטרה בתאריך" with "↺" wraps, so the status line is two lines tall even while it says "המספרים שלכם". **Why:** principle 21 says it must never change height. A fixed height would cut text at other widths, and an ellipsis would hide the example's name. **Where:** `Questions.svelte` `.status`, `WhenField.svelte` `.box`.
- **What:** the years/months switch is the site's `Choices` segmented control, and so is the 2×2 group (with `wraps`, laid out as a grid). **Why:** principle 7, one form for one kind of question. **Where:** `WhenField.svelte`.
- **What:** "↺ חזרה למספרים שלכם" restores the answers, the choices made in the answer, "מתי" with its hidden date and ages, and the unit. The bank stays as it is now. Changing any field over an example drops what was kept, as in the frame. **Why:** "puts them back exactly" (§4.2), principle 22. **Where:** `app.svelte.ts` (`Stash`, `pickExample`, `backToYours`).
- **What:** the list has a ✕ close button on both desktop and phone. The phone frame (`PhoneExA`) shows none. **Why:** a sheet that closes only by tapping beside it gives a keyboard or screen‑reader user no visible way out. **Where:** `Examples.svelte`.
- **What:** picking an example on a phone no longer scrolls to the answer. The old layout test that required the scroll now checks that the "דוגמאות" button stays where it was. **Why:** §4.3, "the page never scrolls by itself". **Where:** `Questions.svelte`, `tests/layout.spec.ts`.
- **What:** links carry `iv=1|0` (already invested) and `ad=0`, written only where the fields differ from the example the link names. Old `v=2` links still open as before. **Why:** a link from the "כרית ביטחון" example with a typed date used to keep "needed any day". **Where:** `link.ts`, `app.sharedState`.
- **What:** each example's numbers line ("₪100,000 ועוד ₪2,000 בחודש, 3 שנים") is built on the web side from `t` templates. **Why:** no Rust in P2. It's a sentence about money, so it belongs in `describe/`: P1 or P4 should move it there next to the collapsed facts line (§4.3), which says nearly the same thing. **Where:** `examples.ts` `numbersLine`, `text/he.ts` P2 block.
- **What:** the situations' explanation and lesson tips are no longer shown: the list has only the name and the numbers, as §4.2 says. The tips' tests in `tips.spec.ts` went with them. **Where:** `Questions.svelte`, `tests/tips.spec.ts`.
- **What:** the layout rule "sticks out of a card" now treats an open dialog inside a card (the examples sheet) as a box of its own. **Why:** the phone sheet is in the top layer, over the whole screen, and isn't part of the card. **Where:** `tests/layout.spec.ts`.
